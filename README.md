# Flipit! 🎮

A 2D physics-based balancing game built in **Unity 6**. Keep your footing on a tilting beam, launch yourself across slopes, and flip the platform a full 180° to score points!

## 📱 Download & Play (Android)
1. Go to the **[Releases Page](../../releases)** on the right sidebar.
2. Download the latest **`.apk`** file onto your Android device.
3. Open the file in your phone's File Manager and allow installation from unknown sources to play.

## 🕹️ How to Play
* **Desktop:** Press **A** to run Left and **R** to run Right.
* **Android:** Tap and hold the **Left** or **Right** half of your screen to move.
* **Scoring:** Spin the platform completely upside down (**180°**) to earn **+5 points**. Your highest score is saved automatically!

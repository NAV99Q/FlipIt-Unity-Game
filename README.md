# FlipIt-Unity-Game
First Game I created with Unity......It is a 2d Game which has one system and scoring method along with working Controls for Both Windows and Android.

[How to Play}
 Use the keys A(for left) and R(for Right) in windows and in Android simply click right and left side of screen when in landscape mode.
 You see Your Score and Best Score after Game Over.
 You can keep retrying and try to get a high score(100 ;)) 

 The Game is Simple to play and Tidy for even 6 Years olds.
